Clone the repository and read README.md, ASSET_INVENTORY.md, and docs/CONTENT_ASSUMPTIONS.md. The current scope is three short homepage concepts with a fixed top 1 / 2 / 3 switcher, autoplaying muted supplied video, and one supporting section. Concept 2 follows the supplied bold personal-brand split-layout inspiration. No backend or live inquiry destination is configured. GitHub pushes trigger Vercel deployments. No Vercel token or other secret is required in the project source or runtime.

The prior ChatGPT Sites deployment is separate and is not required to develop or deploy this project.
